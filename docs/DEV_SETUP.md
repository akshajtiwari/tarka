# Dev setup

Everything installs into your home folder. No sudo is needed and your shell profile is never changed.

## One-time setup (Linux)

```bash
npm install                    # also points git at .githooks (commit-msg + auto push)
scripts/setup-android.sh       # JDK 17, Android SDK, emulator "tarka", Maestro (~8 GB, ~45 min)
```

What `setup-android.sh` installs:

| Tool | Where | Notes |
|---|---|---|
| JDK 17 (Temurin) | `~/.local/jdk-17` | React Native 0.86 builds with JDK 17 |
| Android SDK | `~/Android/Sdk` | platform 36, build-tools 36.0.0, NDK 27.1.12297006, cmake 3.22.1, emulator, x86_64 image. The versions come from `node_modules/react-native/gradle/libs.versions.toml`. |
| Emulator | AVD `tarka` (Pixel 7, Android 16) | needs `/dev/kvm` for speed |
| Maestro | `~/.maestro/bin` | UI test runner |

`scripts/env.sh` sets `JAVA_HOME`, `ANDROID_HOME` and `PATH`. Every script sources it.
Run `source scripts/env.sh` to use `adb`, `emulator` or `maestro` in your own terminal.

Note: Google has deprecated `sdkmanager` in favour of the new `android` CLI.
`sdkmanager` still works and forwards to `android sdk install`.

## Daily loop

| I want to… | Run |
|---|---|
| start the emulator (headless) | `scripts/emulator.sh` (add `--show` to see the window) |
| build and install the dev app | `npm run android` (only needed again after native changes) |
| start Metro with hot reload | `npm start` |
| run on my phone | plug in the phone, then run `scripts/phone.sh` |
| take a screenshot | `scripts/shot.sh <name>`, which saves to `.artifacts/screens/<name>.png` |
| run all checks | `npm run check` |
| run UI tests | `npm run e2e` |

## Phone setup (Android, once)

1. Settings → About phone → tap **Build number** 7 times to enable Developer options.
2. Developer options → turn on **USB debugging**. On Android 11+ you can use **Wireless debugging** instead.
3. Connect the phone:
   - **USB:** plug it in and accept the "Allow USB debugging" prompt.
   - **Wi-Fi:** tap *Pair device with pairing code*. Run `adb pair <ip:port> <code>`, then `adb connect <ip:port>`.
4. Run `scripts/phone.sh`. The first run builds and installs the app (a few minutes). After that it just reconnects and hot-reloads.

## Native folders

`android/` and `ios/` are generated by `npx expo prebuild` / `npm run android` and are **not committed**.
Native settings belong in `app.json` (and config plugins), never in hand edits to `android/`.
